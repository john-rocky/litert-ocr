    What this page does
    
      
    Photos and screenshots are read with worker.recognize(file): every text line, its box, in reading order. PDFs, scans and the Markdown and JSON tabs use convert(file): pages with a text layer are read from it, scanned pages by OCR, and the lines become headings, paragraphs, lists and tables.
    
      
    Your files are read in this tab. The page downloads only the litert-ocr library and pdf.js from jsDelivr and the model files from Hugging Face, once: about 80 MB on the first visit (Chrome 155 on a Mac, 2026-10-22). The browser keeps them, and an open page goes on reading with no network (tested in Chrome on a Mac and on an Android phone in airplane mode). Opening the page again with no network worked in Chrome on a Mac, not in Chrome on Android.
    
      
    The time shown is from handing the file to the library to the result, with the model already loaded. PDFs are read up to 20 pages per file here.
